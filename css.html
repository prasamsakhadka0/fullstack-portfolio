What is CSS?

CSS (Cascading Style Sheets) is used to style and layout web pages. It controls colours, fonts, spacing, and how elements are arranged on screen. CSS works by selecting HTML elements and applying styles to them.

Key CSS Concepts

CSS works using a cascade — styles are applied in order of specificity and importance. Inheritance means child elements inherit styles from their parent. Specificity determines which style wins when multiple rules target the same element.
