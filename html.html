What is HTML?

HTML (HyperText Markup Language) is the standard language used to create web pages. It uses elements represented by tags to structure content on the web.

Why Semantic HTML Matters

Semantic HTML uses meaningful tags that describe the content they contain. This improves accessibility, SEO, and maintainability of web pages.

Demo 1 — Semantic Structure

This page uses semantic elements including:

  • <header> — defines the page header
  • <nav> — defines the navigation links
  • <main> — defines the main content area
  • <footer> — defines the page footer
  • <article> — defines independent content
  • <section> — defines a section of content

Using these tags instead of generic <div> tags makes the page more meaningful to browsers and screen readers.
