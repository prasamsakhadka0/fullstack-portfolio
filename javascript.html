What is JavaScript?

JavaScript is a programming language that makes web pages interactive and dynamic. It runs in the browser and can manipulate the DOM (Document Object Model) — the structure of a web page — in real time without reloading the page.

JavaScript supports variables, functions, events, arrays, objects, and asynchronous programming using Promises and the Fetch API.
