What is Bootstrap?

Bootstrap is a free, open-source CSS framework that helps developers build responsive, mobile-first websites quickly. It provides pre-built components like navbars, cards, buttons, and modals, along with a powerful 12-column grid system.

Instead of writing all CSS from scratch, Bootstrap gives you ready-made classes you can apply directly to HTML elements. You can also customise Bootstrap by overriding its default styles with your own CSS.

Demo 1 — Bootstrap Grid System

Bootstrap uses a 12-column grid. Columns are defined using classes like col-md-4 (4 out of 12 columns on medium screens). The grid is responsive — columns stack on mobile and sit side by side on larger screens.

Demo 6 — Bootstrap vs Custom CSS

Use Bootstrap when:

  • You need to build a prototype or project quickly
  • You want a consistent, professional look out of the box
  • You need reliable cross-browser compatibility

Use Custom CSS when:

  • You need a unique, bespoke design
  • You want full control over every style
  • File size and performance are a priority
